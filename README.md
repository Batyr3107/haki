# 💡 LifeHacks - Платформа для обмена лайфхаками

Современная веб-платформа для обмена полезными советами и лайфхаками между парнями. Делитесь своими идеями, оценивайте лучшие лайфхаки и общайтесь с единомышленниками!

## 🚀 Особенности

### Основной функционал
- ✅ **Регистрация и аутентификация** - Безопасная система входа с хешированием паролей
- 📝 **Создание и публикация** - Делитесь своими лайфхаками с сообществом
- ✏️ **Редактирование и удаление** - Полный контроль над своим контентом
- ⭐ **Система оценок** - Оценивайте лайфхаки от 1 до 5 звезд
- 💬 **Комментарии** - Обсуждайте и оставляйте отзывы
- 👤 **Профили пользователей** - Подробная статистика и история публикаций
- ❤️ **Избранное** - Сохраняйте интересные лайфхаки в избранное

### Контент и форматирование
- 📝 **Markdown поддержка** - Форматируйте текст с помощью Markdown
- 👁️ **Предпросмотр** - Просматривайте результат перед публикацией
- 🔗 **Гиперссылки** - Добавляйте ссылки на внешние ресурсы
- 💻 **Код** - Вставляйте фрагменты кода с подсветкой
- 📋 **Списки** - Создавайте нумерованные и маркированные списки

### Социальные функции
- 🔗 **Социальный шеринг** - Делитесь через VK, Telegram, WhatsApp, Facebook, Twitter
- 📋 **Копирование ссылки** - Быстрое копирование ссылки в буфер обмена
- 📱 **Адаптивные кнопки** - Оптимизированы для всех устройств

### Навигация и поиск
- 🔍 **Умный поиск** - Поиск по названию, описанию и автору с debouncing
- 📊 **Сортировка** - По дате, рейтингу или популярности
- 🏷️ **Категории** - Технологии, кухня, здоровье, финансы, дом, автомобиль
- 📄 **Пагинация** - Удобная навигация по страницам
- ⬆️ **Scroll to Top** - Быстрый возврат к началу страницы

### Дизайн и UX
- 📱 **Адаптивный дизайн** - Отлично работает на всех устройствах
- ⚡ **Быстрая загрузка** - Оптимизированная производительность с debouncing
- 🎨 **Современный UI** - Красивый интерфейс с Tailwind CSS
- 🔄 **Real-time updates** - Мгновенное обновление без перезагрузки
- 💀 **Skeleton Loaders** - Плавная загрузка контента
- 🎯 **Toast уведомления** - Информативные всплывающие сообщения

## 🛠 Технологии

- **Frontend**: Next.js 15, React 18, TypeScript
- **Styling**: Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: SQLite с Prisma ORM (поддержка PostgreSQL, MySQL)
- **Authentication**: NextAuth.js
- **Markdown**: react-markdown, remark-gfm
- **Date formatting**: date-fns с русской локализацией
- **Security**: bcryptjs для хеширования паролей

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd haki
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения:
Файл `.env` уже создан со следующими переменными:
```env
DATABASE_URL="file:./dev.db"
NEXTAUTH_SECRET="your-secret-key-change-in-production"
NEXTAUTH_URL="http://localhost:3000"
```

**ВАЖНО**: Измените `NEXTAUTH_SECRET` на случайную строку в продакшене!

4. Инициализируйте базу данных:
```bash
# Если есть проблемы с Prisma, используйте:
PRISMA_ENGINES_CHECKSUM_IGNORE_MISSING=1 npx prisma generate

# Создайте базу данных:
npx prisma db push
```

5. Заполните базу тестовыми данными:
```bash
npm run db:seed
```

## 🎯 Использование

### Для новых пользователей:

1. **Регистрация**: Перейдите на страницу регистрации и создайте аккаунт
2. **Вход**: Войдите используя свой email и пароль
3. **Просмотр**: Просматривайте лайфхаки на главной странице
4. **Поиск**: Используйте поиск и фильтры по категориям
5. **Создание**: Нажмите "Создать лайфхак" чтобы поделиться своими идеями
   - Используйте Markdown для форматирования текста
   - Переключайтесь между редактором и предпросмотром
6. **Оценка**: Оценивайте лайфхаки от 1 до 5 звезд
7. **Избранное**: Добавляйте понравившиеся лайфхаки в избранное
8. **Комментарии**: Оставляйте комментарии и обсуждайте лайфхаки
9. **Редактирование**: Редактируйте или удаляйте свои лайфхаки
10. **Шеринг**: Делитесь лайфхаками в социальных сетях
11. **Профиль**: Просматривайте свой профиль и статистику

### API Endpoints:

**Аутентификация:**
- `POST /api/auth/register` - Регистрация нового пользователя
- `POST /api/auth/[...nextauth]` - Аутентификация

**Лайфхаки:**
- `GET /api/lifehacks` - Получить все лайфхаки (с фильтрацией, поиском, сортировкой)
- `POST /api/lifehacks` - Создать новый лайфхак
- `GET /api/lifehacks/[id]` - Получить конкретный лайфхак
- `PATCH /api/lifehacks/[id]/edit` - Редактировать лайфхак (только автор)
- `DELETE /api/lifehacks/[id]/edit` - Удалить лайфхак (только автор)

**Рейтинг и комментарии:**
- `POST /api/ratings` - Оценить лайфхак
- `POST /api/comments` - Добавить комментарий

**Избранное:**
- `GET /api/favorites` - Получить избранные лайфхаки
- `POST /api/favorites` - Добавить/удалить из избранного (toggle)

**Пользователи:**
- `GET /api/users/[username]` - Получить профиль пользователя

## 📝 Модели данных

### User (Пользователь)
- username, email, password
- name, bio, avatar
- Связи: lifehacks, ratings, comments, favorites

### Lifehack (Лайфхак)
- title, description, content
- category, views
- Связи: author, ratings, comments, favorites

### Rating (Оценка)
- value (1-5)
- Уникальное ограничение: user + lifehack
- Связи: user, lifehack

### Comment (Комментарий)
- content, createdAt
- Связи: user, lifehack

### Favorite (Избранное)
- createdAt
- Уникальное ограничение: user + lifehack
- Связи: user, lifehack

## 🐛 Troubleshooting

### Проблемы с Prisma:
Если возникают проблемы с загрузкой Prisma engines:
```bash
PRISMA_ENGINES_CHECKSUM_IGNORE_MISSING=1 npx prisma generate
```

### Сброс базы данных:
```bash
rm -rf prisma/dev.db
npx prisma db push
```

### Проблемы с портом:
Если порт 3000 занят, измените порт:
```bash
PORT=3001 npm run dev
```
